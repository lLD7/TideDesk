# TideDesk

## 0.9.0

- 应用正式更名为 TideDesk，保留原有深色界面和图标。
- 增加菜单及日志页“检查更新”，支持中文原生更新窗口、下载进度、稍后提醒与跳过版本。
- 默认启动后检查更新，运行期间每 24 小时检查一次，可在日志页关闭。
- 更新包使用 Ed25519 签名，发布来源为 lLD7/TideDesk。
- 压力分布按现价百分比筛选，默认 ±10%，支持 ±1%～±50%。
- 保留旧版 GammaGrid 的本地数据位置；更新时释放数据库锁，再启动新版。

本版本是自动更新起始版本。旧版 GammaGrid 0.8.x 需要手动安装一次 TideDesk；后续版本可在应用内更新。
此版本使用本地签名，尚未 Apple Developer ID 签名或公证。
